# MiniFeather Client

> A custom client for [Miniblox.io](https://miniblox.io) — open source (GPL-3.0), client-side.

MiniFeather adds FPS boost, texture packs, custom shaders, Baritone, a minimap, waypoints, custom skins and 60+ more modules to Miniblox, the browser voxel game. It's free, it updates itself, and it works on desktop and mobile.

This repository is the client's landing page — the source code lives at [DevOfficial-Client/MiniFeather-Client](https://github.com/DevOfficial-Client/MiniFeather-Client), readable, under GPL-3.0. Star the real thing. ⭐

## Open source

* The whole client is readable in the [source repo](https://github.com/DevOfficial-Client/MiniFeather-Client) under GPL-3.0. Even the distributed [`minified`](https://github.com/DevOfficial-Client/MiniFeather-Client/tree/minified) branch is generated by a public workflow, so nothing ships that you can't read.
* You sign into Miniblox the same as always. Whatever the client stores locally is listed in plain language in the [EULA](https://github.com/DevOfficial-Client/MiniFeather-Client/blob/main/EULA-TLDR.en.md).
* No ads, no miners, no premium tier — it's a community project, developed in the open, with tests.
* A documented kill-switch config ([EULA 8.5](https://github.com/DevOfficial-Client/MiniFeather-Client/blob/main/EULA.md)) can disable the client remotely if a build ever misbehaves. That part is in the open, too.

## Download & install

Free on every platform, and every package updates itself.

**Desktop — userscript (easiest)**

1. Install a userscript manager: [Tampermonkey](https://www.tampermonkey.net/) (Chrome/Edge/Firefox) or [Violentmonkey](https://violentmonkey.github.io/).
2. Open [dist/MiniFeatherClient.user.js (raw)](https://raw.githubusercontent.com/DevOfficial-Client/MiniFeather-Client/main/dist/MiniFeatherClient.user.js) — the manager installs it, and from then on it auto-updates.
3. Play at [miniblox.io](https://miniblox.io).

**Android (APK)** — from the rolling [builds release](https://github.com/DevOfficial-Client/MiniFeather-Client/releases/tag/apk-latest) (Windows MSI and Linux AppImage/deb live there too).

**iOS (Safari)** — install the free [Userscripts](https://github.com/quoid/userscripts) app, allow it on `miniblox.io`, and add a new script from the same userscript URL.

**Chrome/Chromium extension** — load the full MV3 extension unpacked from the [source repository](https://github.com/DevOfficial-Client/MiniFeather-Client).

**Desktop Launcher (PixelVortex)** — the PixelVortex Launcher by ShusukeGxE for Windows, Linux and macOS bundles MiniFeather with an account manager and automated updates.
